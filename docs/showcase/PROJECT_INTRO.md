## 300 字版

> **饭搭子 AI（MealMate AI）是一个餐饮决策与预算管理助手。**
>
> 它要回答三个问题：今天吃什么、预算够不够、花完还剩多少。
>
> 大多数点餐工具的答案是「这一单多少钱」。但对生活费按月分配的人来说，真正的问题是
> 「这顿吃完，后面几天怎么过」。所以这个项目把「单笔消费」放回「周期预算」里重新算一遍。
>
> 你只需说一句「今天只有 25 元，想吃鸡肉，不要太辣」。系统会解析出预算上限、餐次、口味偏好和排除项，
> 然后去麦当劳官方 MCP 拉取真实门店菜单，对每一个候选组合调用官方算价接口核价，超预算的直接剔除换下一个。
> 最后给三份不同取向的方案——省钱优先、均衡选择、满足优先——每份都标注官方核价和「扣掉后还剩多少」。
>
> 在长期预算页，你可以建一个月度预算，记下每笔真实消费。每记一笔之前，
> 它会先告诉你「吃这顿之前日均多少、之后日均多少」，把单笔开销的影响摆在明面上。
>
> 三条边界：**不提供下单、支付、领券等任何交易能力**（只读查询）；
> **推荐结果绝不自动记账**，扣预算必须你亲自确认；**预算数据只存在你自己的浏览器**，没有云端同步。
>
> 技术上它只用了麦当劳三个只读接口（查门店、查菜单、算价格），
> 代码以 MIT 协议开源，474 项单元测试、26 项真实接口集成测试、69 项浏览器端到端断言全部通过。

## 三条必须说清的事实边界

对外介绍时，以下三点**不能说反**，否则属于不实陈述：

| 事实 | 正确说法 | 错误说法 |
|---|---|---|
| **大模型状态** | 当前运行在**规则解析模式**（未配置 `AI_API_KEY`），页面有「规则解析（未接入大模型）」徽标；配置密钥后会自动切换，但**真实模型回归尚未验证** | 「接入了大模型」「由 GPT 智能推荐」 |
| **在线服务** | 代码在 GitHub **公开可读**，但**没有部署线上演示站**，需本地运行 | 「在线体验地址：…」「已上线，扫码即用」 |
| **数据来源** | `/` 和 `/budget` 是**真实 MCP 接口实时数据**；`/demo` 是**一次真实查询的冻结快照**（不联网） | 把 `/demo` 的截图说成「实时查询」 |

补充说明：

- `query-nearby-stores` / `query-meals` / `calculate-price` 三个接口是**真实调用的**，
  调用记录与字段契约见 [`../../MCP_INTEGRATION.md`](../../MCP_INTEGRATION.md)。
- 截图中的价格是**某次真实查询**的结果，换门店、换时段会变；不要把截图数字当成固定报价。
- 项目**不是**麦当劳官方产品，与麦当劳没有隶属或合作关系，详见 README「项目定位与身份声明」。
