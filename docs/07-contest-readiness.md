## 4. 三段可复现演示

新增 `scripts/demo-check.mjs` 与 `npm run demo:check`，**不依赖浏览器**即可复现前两段；

### 4.1 第 1 段：一句话推荐（已脚本化）

| 项 | 内容 |
|---|---|
| 输入 | 「今天中午只有 25 块，想吃鸡肉，不要太辣。」 |
| 接口 | `POST /api/ai/decide` |
| 断言 | 解析出预算 ¥25.00 / 解析模式已标注 / 来源 provider+traceId 可追溯 / 每份方案 ≤ 预算 / 每份 `priceVerified` |

**本次实测输出**（2026-10-22 19:40，门店 1400359，`mode: RULE_FALLBACK`）：

| 方案 | 金额 | 扣掉后还剩 |
|---|---|---|
| 均衡选择 | ¥15.90 | ¥9.10 |
| 省钱优先 | ¥13.90 | ¥11.10 |
| 满足优先 | ¥25.00 | ¥0.00 |

> 「满足优先」恰好卡在 ¥25.00、剩余 ¥0.00，是**合规**结果（不超预算），
> 不是四舍五入误差——价格来自 `calculate-price` 的整数分。

### 4.2 第 2 段：手动预算推荐（已脚本化）

| 项 | 内容 |
|---|---|
| 输入 | 预算 ¥20.00（不经自然语言） |
| 接口 | `POST /api/recommend` |
| 断言 | 每份 ≤ ¥20.00 / 每份已核价 / 方案数 1~3 均合法 |

**本次实测输出**：省钱 ¥13.90（剩 ¥6.10）· 均衡 ¥15.90（剩 ¥4.10）· 满足 ¥20.00（剩 ¥0.00）。

### 4.3 第 3 段：长期预算 Meal Impact（浏览器）

**步骤**：

1. 打开 `/budget`；
2. 首次进入设置周期预算（如每月 ¥900）→ 保存；
3. 在「吃这顿之前 / 之后」面板输入 25（或点 ¥25 快捷键）；
4. 应看到一句结论：「如果花 ¥25.00，接下来 N 天平均每天还能安排 ¥X」，
   以及「吃这顿之前 → 吃这顿之后」的余额与日均对比；
5. 点「记为已消费」→ 金额进入账本 → **刷新页面记录仍在**（localStorage）；
6. **反向核对**：只输入金额不会自动记账，必须点确认按钮才写入。

**自动化覆盖**：浏览器 E2E 中已含预算页 4 条、Meal Impact 对比、记账后刷新保留、
移动端表单等断言（见第 5 节 69 条断言）。
